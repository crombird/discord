### @crombird/discord

crom's discord bot. [add to discord here](https://discord.com/oauth2/authorize?client_id=418818217016819749).

built with [bun](https://bun.sh/) and hosted on [fly.io](https://fly.io). heavily integrates with crom internal apis for linked accounts, server metadata, reading lists, diaries, and other features.

currently only supports english, but if it finds use in a different language server, support with translations are appreciated. [join the support server](https://crom.avn.sh/support-server) if you'd like to help with translations.
